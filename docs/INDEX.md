# Aurora help and documentation

Aurora Intel `0.1.0-alpha` is a local, offline-first intelligence ledger. Choose the documentation for your role:

The same essential guidance is available inside the running application from **Help and documentation** in the top bar, split into user and technical/admin views.

| Page | Use it for |
|---|---|
| [User documentation](user/INDEX.md) | Start/stop, 7S intake, source assessment, ledger, weather, map and automated assessment |
| [Technical documentation](technical/INDEX.md) | Architecture, local model, security, offline packaging, schema and maintenance |

For an operational problem, first confirm the classification/handling rules for the workstation, then use [Start and stop](user/START.md). Aurora does not replace command systems, safety systems, navigation tools or organizational security controls.
